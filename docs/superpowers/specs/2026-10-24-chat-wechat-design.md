# 对话、本人阅读、语音结束与微信接入

用户本轮要求：聊天式历史可展开/收起；本人能看自己的整理结果；开场称呼可记忆；听到停止意愿后实际结束；腾讯云、个人主体、查询paperlife.ai等域名，推进小程序和微信登录。

## 本轮实现选择

沿用已授权持续实现/发布流程。网页继续在当前试用站迭代；国内迁移需云账号、实例和合适域名等输入，不虚构已迁移。采用原生微信小程序客户端直接连接现有REST/WSS服务，不以个人主体可使用web-view套壳为前提。

官方资料显示个人主体无法申请深度合成类目，本产品的AI采访/故事生成很可能需要该类目；先准备代码和网页，正式小程序上架须核实合适主体与算法材料。wx.login与手机号能力分开，不强制取手机号。个人云账号可先开发，不自动购买或变更主体。

## 产品与权限

- 当前对话为左右消息气泡，默认可见历史；可折叠为当前问题。访谈中可浏览过去会话，不结束正在进行的录音，也不强制滚动打断阅读。
- 讲述者专属链接增加绑定档案的只读历史、原声和已确认人生之书。服务端从链接推导档案，不相信客户端传入档案ID；不能读取其他人的资料、未确认草稿、编辑或授权。家人原来的整理界面保留。
- 用户确认两种称呼都支持：给AI取名，以及明确的“叫我某某”本人称呼请求。只从最终发言中的明确请求或开场正在等待的简短命名回答学习。名字长度/字符限制，有来源，可撤销；不替换法律身份，不将名字当系统指令。
- 停止意图使应用真正结束收音和会话、保存并自动整理。启用豆包退出意图信号，加明确最终语句检测；引述往事、否定“不要停”和临时ASR不触发。向客户端发ending，客户端立即停麦，服务端最终发ended。按钮保留作为备用。

## 接口约定

- GET /life/guest/history?offset=0&limit=20 → {sessions:[{id,title,status,created_at,version}],has_more:bool}。
- GET /life/guest/history/{session} → 当前档案会话与turns；GET相同路径/audio?track=user|assistant → 私有WAV。所有请求用X-Life-Link。
- GET /life/guest/book → {items:[仅confirmed],pending_count:int}。保留来源定位信息但不暴露draft内容。
- 账号端对应 /life/profiles/{profile}/history 和 /life/profiles/{profile}/book；已有 /life/sessions/{id} 读详情/音频。
- POST sessions增加transport: web|wechat（默认web）。浏览器仍核验同源；原生小程序在一次性票据、绑定用户/链接授权验证后才允许缺省或微信平台Origin，不能据transport标记绕过权限。
- 小程序先wx.login→/auth/wechat，再读获授权档案或创建本人空档案。收到invite查询参数时保留原有capability作用域，不自动把邀请变成管理员/永久成员身份。

## 验收

停止意图肯定/否定/引述/临时识别，存档尾句与幂等结束；两类名字隔离/撤销/注入边界；guest跨人/草稿/无效链接拒绝；聊天折叠与历史阅读不中断录音；小程序配置缺失明确失败、登录code由服务器兑换、PCM采集播放按微信真实能力验证。真AppID/真机、备案和审核仍是独立门槛。

## 执行补充

用户确认先上线网页、准备原生小程序，后续办理个体工商户。腾讯云已登录并配置报价，但用户明确暂不购买；本轮不创建云资源或导入SSH公钥。审查修复包括退出否定作用域、等待final后消费供应商退出信号、保守命名以及小程序改名后同步显示。
