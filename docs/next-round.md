# 下一轮用户待办包

按顺序做；没有准备好的项无需为了继续开发而一次性完成。不要把身份证、密码、API Secret、短信验证码贴到聊天或GitHub。

## A. 先决定三件事

1. **云与地域**：建议腾讯云中国大陆；有现成火山/阿里企业资源也可。提供云厂商、地域、服务器登录方式或受限子账号授权。先用2核4GB、小规模私有数据盘做预发布；容量与费用需按控制台当时规格确认，不据此自动采购。
2. **主体**：个人、个体工商户还是公司？决定小程序类目、手机号能力、短信签名可用资质。个人并不自动被排除，但不要预设所有能力都开放。
3. **域名**：准备独立域名/子域名，完成域名实名。大陆网站接入备案与小程序备案分别核实；现有境外网站可访问不代表满足小程序/大陆接入要求。

## B. 控制台必须本人完成的工作

- 云账号实名认证；确认服务器采购预算、存储/流量预算和账单告警。
- 域名实名、所需备案流程、接入商校验（通常会涉及证件、短信核验等）。
- 微信公众平台注册小程序，确认主体/服务类目/隐私规范；取得AppID、配置合法HTTPS/WSS请求与上传下载域名；确认录音权限和手机号能力资格。AppSecret只放服务端。
- 腾讯短信：完成需要的资质、签名和验证码模板审核。当前代码模板参数为验证码、有效分钟数两个参数，须与实际模板一致；取得SmsSdkAppId/SignName/TemplateId。通过最小权限子账号提供发送能力，设置额度和告警。
- 豆包：已有语音凭据可继续用；确认允许的调用区域、数据处理条款及预算。若希望后台整理换专门文本模型，再开通文本模型与独立受限Key。
- 生产数据同意：明确讲述者知道录音/转写会由哪些服务处理，哪些亲属能看，以及如何撤销分享/导出。朋友使用也要有这条流程。

## C. 安全提供配置

可提供非秘密信息：地域、域名、小程序AppID、签名/模板ID、预期人数、每天访谈分钟数。秘密通过部署环境秘密管理或本机私有文件交付，不提交`.env`。不要启用公开对象存储桶。

## D. 收到配置后可继续执行

1. 部署国内预发布，配置HTTPS、受限凭据、私有存储和备份。
2. 用Android/iPhone微信和系统浏览器，对比GCP与国内预发布的真实语音延迟及稳定性。
3. 验收四川话理解/输出、一次中性澄清、接受“不记得”、疲惫/拒绝信号、原文留存。
4. 联调真实短信与微信code登录；实现并提交原生小程序采集端。
5. 安排停写窗口迁移家人数据、成员、链接hash，逐个验证旧链接、阅读权限、原声和待审稿；再切生产域名。
